# 幸存者 · 脉冲

15 分钟一局，自动开火，三层成长（武器 / 技能 / 被动），手机与桌面都可玩。

> **武器、技能、被动全部上限 5 级**；升级卡用五格进度显示，满级卡显示 MAX + 金边呼吸 + 底部冒火。

## 一、怎么玩


| 操作 | 桌面                | 手机          |

- **攻击全自动**，你只需要走位、躲弹幕、捡经验。
- 冲刺带来 **0.17 秒无敌位移**，冷却 2.6 秒（局外「超频单元」可缩短）。
- 目标：**撑到 15:00**。击杀 **14:00 出现的终局 Boss** 后裂隙开启，可提前撤离结算（撤离另有奖励）。

## 二、三层成长体系

### 1. 武器（最多 3 把，决定你的普攻动作）

开局只有**角色本命武器**，另外两把要靠**宝箱解锁**。

| 武器 | 上限 | 普攻 | 进化（宝箱：武器 Lv ≥ 3 + 对应被动 1 级） |
| --- | --- | --- | --- |
| **脉冲**（蓝） | 5 | 朝最近敌人点射，**射程 6 格**，**攻速 4.7→9.5 次/秒**，伤害 1.8+0.55/级 | **千针**（需 **增幅** 1 级）：普攻**弹道数 ×2**（永久生效）· **必定穿透** · 单发伤害 -30% |
| **暗黑**（紫） | 5 | 推出紫黑球体，**射程 4 格**，飞满射程才消散，扫到的敌人各掉一次血，攻速 0.76→1.80 次/秒 | **奇点球**（需 **扩散** 1 级）：半径 +40% · 命中减速 40% · **飞满射程后转身飞回人物身上**，返程再判一次二段伤害 |
| **弧刃**（绿） | 5 | 朝移动方向挥出 90° 刀光，**射程 2 格**，**每个敌人只判一次**，攻速 1.45→3.25 次/秒 | **双月**（需 **疾行** 1 级）：左右两侧各补一刀 120° 弧（半径 +28%）· 伤害 +40% |

**弹道展开规则（只看数量，和来源无关）**：第 1 道正中，之后 **左 1 档 → 右 1 档 → 左 2 档 → 右 2 档 …** 交替加档，每档偏移约 0.085 rad。

- 1 发：正中
- 2 发：正中、左侧一点
- 3 发：正中、左侧、右侧
- 4 发：正中、左、右、更左、更右……

> 弹道数 = **1（自身）+ 脉冲炮等级**；只要武器进化成 **千针**，结果整体 **×2**（永久）。例：脉冲炮 5 级 → 1+5 = **6 道**；千针后 **12 道**。

> 进化**不改变攻速**，只在穿透与伤害结构上做文章。

### 核心概念：普攻 / 冷却 / 挂载


| 概念           | 规则                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------- |
| **普攻**       | 与武器**攻速**（次/秒）绑定，**没有冷却**。攻速 1 = 每秒出手 1 次                                   |
| **冷却（CD）** | 只属于**主动技能**；「超频」只缩短技能冷却，永远不影响普攻                                          |
| **普攻挂载**   | 是**普攻的附加特效**，没有独立出手、没有冷却，普攻命中/暴击时顺带触发（脉冲炮、暴击飞弹、双剑滑斩） |

### 2. 技能（场上术法，按**族**归属：3 族 ×3 个 + 5 个通用）

技能不绑定某一把武器，而是绑定**武器族**（脉冲族 / 暗黑族 / 弧刃族）。同族里将来加新武器，技能可以共用，技能池也就不再被武器数量锁死。

| 所属 | 技能                 | 上限 | 效果                                                                                             |
| ---- | -------------------- | ---- | ------------------------------------------------------------------------------------------------ |
| 脉冲 | 脉冲炮（挂载）       | 5    | **普攻直接多射出 N 道**（N = 等级，扇形展开）；不带穿透，也没有独立冷却；千针后随弹道数一起翻倍  |
| 脉冲 | 连锁闪电             | 5    | 电弧在敌人间跳跃 2+级 次，每跳造成伤害                                                           |
| 脉冲 | **暴击飞弹**（挂载） | 5    | 普攻暴击时弹出一枚弧形飞弹回击该目标，伤害为本次伤害的 50%+5%/级                                 |
| 暗黑 | 引力井               | 5    | 在敌群生成引力井，持续拉拽 + 周期性伤害                                                          |
| 暗黑 | 湮灭鱼雷             | 5    | 发射追踪鱼雷，命中后坍缩爆炸                                                                     |
| 暗黑 | 轨道打击             | 5    | 锁定数个敌人，天降光柱                                                                           |
| 弧刃 | 疾风斩               | 5    | 甩出旋风，穿过的敌人各受一次伤害                                                                 |
| 弧刃 | 回旋斩               | 5    | 刀身飞出到最大距离后**飞回人物**，**去/回各判 1 次**                                         |
| 弧刃 | **双剑滑斩**（挂载） | 5    | 普攻时朝**反方向**再补一刀，伤害为普攻的 60%+8%/级；和双月叠加就是「前 1 + 后 1 + 左右 2」共四刀 |
| 通用 | 冲击新星             | 5    | 以自身为中心释放冲击波，伤害 + 击退                                                              |
| 通用 | 陨石天罚             | 5    | 标记敌人最密处，0.6 秒后陨石砸下，大范围高伤害 + 震屏                                            |
| 通用 | 冰封棱镜             | 5    | 环形冰爆，命中的敌人冻结（冻结期间受伤 ×1.25）                                                   |
| 通用 | 焚地火海             | 5    | 沿朝向铺 3 段火海，持续 2.6 秒，每 0.4 秒灼烧一次                                                |
| 通用 | 血契汲取             | 5    | 被动：造成伤害的 4%+1.2%/级 转化为治疗，攒满 1 点回 1 血（紫色心形图标，不主动释放） |

> 图标**虚线边框** = **普攻挂载**技能（平时不主动释放，跟着普攻触发）。
> **专属技能需要先拥有该族的任意一把武器才会触发**：没拿到暗黑族武器，抽到的引力井 / 湮灭鱼雷 / 轨道打击照样能升级（等级保留），但不会释放，状态栏图标会压暗；宝箱解锁该族武器后立刻开始生效。通用技能（冲击新星）不受限制。

### 3. 被动（6 个，全部 5 级）

## 三、升级与宝箱

### 升级（三选一）

- 每满一管经验弹 3 张卡，权重 **武器 30% / 技能 40% / 被动 30%**。
- 抽卡偏向**本命角色**：自己的武器 4 份权重、自己的专属技能 7 份、通用技能 3 份、别的武器技能 1 份。
- 卡面颜色即分类：**武器色（蓝 / 紫 / 绿）= 武器与它的专属技能、金色 = 通用技能、银色 = 被动**（和主界面角色主色一致）。
- 卡面角标：**NEW** = 新解锁，**MAX** = 已到 5 级上限（满级卡金边呼吸 + 底部冒火）。
- 每局可以 **刷新选项 3 次**，换一批卡。
- 到 5 级上限的武器 / 技能 / 被动不再出现在卡池里。

### 宝箱

- 来源：**精英怪**死亡掉落，走过去自动打开（精英出现在 1:30 / 3:00 / 7:00 / 11:00）。
- **解锁节奏**：第 2 把武器 **1:30 之后**才能解锁，第 3 把要等到 **8:00 之后**——中后期再补齐三把，避免开局几分钟就把流派吃满。
- 打开后二选一：
  1. **解锁**另一把未拥有的武器；
  2. 让 **武器 LV ≥ 3 + 对应被动已点到 1 级** 且尚未进化的武器**进化**（每把只进化一次）。
- 进化配对（武器 ↔ 被动）：

| 进化 | 武器 | 需要的被动 |
| --- | --- | --- |
| 千针 | 脉冲 | **增幅** 1 级 |
| 奇点球 | 暗黑 | **扩散** 1 级 |
| 双月 | 弧刃 | **疾行** 1 级 |

- 这三种被动就是三把武器的专属进化前置：升级三选一里它们的卡面底部会用**武器族颜色**标一行「脉冲族 / 暗黑族 / 弧刃族 武器进化前置条件」，到 1 级后显示 `LV 1 ✓`。
- 条件没凑齐时，宝箱页底部会提示「进化还差被动：千针 ← 增幅 1 级」，并且**宝箱会把那张缺的被动卡直接放出来**（不再只给一次无用的进化拒绝），点一下就能补 1 级。
- 都没得选时，宝箱退化成 **+2 生命 / +40 金币**。
- 进化后的武器 HUD 图标：颜色不变，左下多一颗**彩色 ★**，右下仍显示等级。

### 补给掉落（走位奖励）

普通怪小概率、**精英与 Boss 必定**掉落下面三种补给，靠近自动吸取：

| 补给 | 外观 | 效果 |
| --- | --- | --- |
| 生命补给 | 红色十字 | 立刻回复 1 点生命 |
| 磁力脉冲 | 紫色磁铁 | 全场经验与金币立刻被吸过来 |
| 湮灭弹 | 橙色圆环 + 旋转三角 | 以自身为中心造成大范围高额伤害 + 击退 |

补给 26 秒后消失，最后 4 秒闪烁提示；幸运会提高掉落概率。

## 四、暴击

- 基础 **暴击率 5%**、**暴击伤害 200%**，全部来自**局外养成**（局内不加暴击属性）。
- **瞄准镜**：暴击率 **+8%/级**，上限 **5 级** → 满级 **45%**。
- **弱点解析**：暴击伤害 **+20%/级**，上限 **7 级** → 满级 **340%**。
- 暴击时飘红字 `#ff4d6d`、字号更大 + 红色爆发粒子 + 轻微镜头震动。
- 挂了 **暴击飞弹** 时，脉冲普攻暴击会额外弹出一枚弧形飞弹追击同一目标。

难度按地图**逐级**解锁（先普通→再强化→再梦魇→再深渊），换地图要重新爬。难度只放大敌人与收益，不改你自己的成长曲线，所以高难度是「更凶但更肥」。

**下一张地图**要上一张图的 4 个难度都达标（各活满 3:00）才开，也就是说「上一张图全部解锁」才会放出下一张。

背景是星空外域风格：深空基底 + 星云 + 三层视差星点 + 星图网格（每 4 格一条主线、交点带星图节点），配色由 `MAPS[].bg` 决定（静寂星野冷蓝紫、陨落回廊暗红紫、后两张占位图各有配色）。

**最佳记录按「地图 × 难度」各存一份**（2 × 4 = 8 份，`save.best["plain:0"]` 这种键，字段 `t/k/c/d/m` = 生存 / 击杀 / 金币 / 总伤害 / 最长连杀）。结算面板只跟**同一组地图难度**的历史比「新纪录」，标题页显示的「最长生存 / 最高击杀」则是所有组合里的总最佳。

## 八、界面上都在看什么

- **左上**：生命 / 冲刺冷却 / 经验（等级）。
- **顶部中央**：剩余时间 + 模式名。
- **左侧**：已获得的武器（1/3）、技能、被动（0/6）；图标配色与升级卡一致（武器色 / 通用金 / 被动银）。
- **右上**：圆形小地图（红点杂兵、橙点精英、红方块 Boss、紫点裂隙、金块宝箱）+ 暂停按钮。
- **右下**：击杀 / 金币 / 伤害数字状态。
- **暂停**里：全部音效开关、伤害数字开关、**音乐音量 / 音效音量**两条滑杆（拖动实时生效，松手试听一声）。这四项存在 `gws_set` 里，游戏数据（金币/强化/角色/记录）存在 `gws_data` 里，两把 key 分开、各自读写。
- **声音**：BGM 是程序化生成的循环（不加载音频文件），跟着战况切三档——平静（菜单）/ 推进（普通战斗）/ 紧张（Boss 在场）。

## 九、上手指南（三句话）

1. **先活下来再贪**：贴边走、绕圈拉怪，冲刺留着躲精英环弹；血少了就找地上的红色十字。
2. **第一次宝箱优先解锁武器**——两把武器的普攻叠加，输出是质变。
3. **LV 3 之后就凑进化**：千针把弹道直接翻倍（6 → 12 道）还带穿透，但需要先把**增幅**点 1 级；奇点球要**扩散**、双月要**疾行**。

## 十、标题页四个入口（局外强化 / 图鉴 / 成就 / 设置）

「开始作战」下面一排图标，从左到右：

- **局外强化**（购物车）：星尘商店，22 项分攻/防/功三型。
- **图鉴**：四个页签 —— 武器（含进化名）、技能（按族分组，标注主动 / 挂载 / 被动转化）、被动、敌人（显示已累计击杀数，没遇过的标「未遭遇」，击杀数来自存档 `killTypes`）。
- **成就**：16 条，分 **击杀 / 成长 / 彩蛋** 三组，每条有进度条；达成后按钮变成金色「领取 ◇ N」，点一下把金币加进存档并记 `save.ach[id]`。配置全在 `src/data.js` 的 `ACH` / `ACH_CATS`，加一条只需要往表里加一项。
- **设置**：与暂停面板同一套四行（全部音效 / 伤害数字 / 音乐音量 / 音效音量），在标题页就能调，照样写 `gws_set`。

标题页本身**不滚动**：内容按窗口高度收紧（`@media (max-height: …)` 逐级压间距，窗口更矮时 `.titlebox` 整体 `zoom` 等比缩小），所以「开始作战」和这排入口永远在首屏。

结算面板现在显示：生存时间 / 等级 / 击杀 / 总伤害 / 承伤次数 / 最长连杀 / 本局金币，破纪录的行会标「新纪录」。
