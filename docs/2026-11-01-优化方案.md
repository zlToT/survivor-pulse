## ①-1 结算复盘（第 8 条）

**决定**：只统计三项，不做「哪把武器打的」伤害占比。

- 总伤害：每次实际造成伤害累加（含暴击加成后）。
- 承伤次数：真正挨打才计数（无敌帧/冲刺/无敌 GM 不计）。
- 最长连杀：击杀连续累加，**挨一次打清零**。
- 三项 + 生存时间 / 击杀 / 本局金币 都有历史最佳，写进 `gws_data`（`bestTime / bestKill / bestCoin / bestDmg / bestCombo`）。
- 结算页右侧小字：破纪录显示金色「新纪录」，否则显示「最佳 N」。

实现：`src/world.js` run 字段 `dmg/hits/combo/comboMax`；`src/combat.js` 伤害累计与击杀连杀；`src/update.js` 受击计数与断连；`src/core.js` 存档字段；`src/ui.js` `commitRun/resultPanel`；`src/style.css` `.stat em`。
